PEMBAYARAN QRIS (SIMULASI) - KUEKU MARINDA
===========================================

PASANG (urut)
1. Extract zip ke folder proyek, timpa file yang sama.
2. phpMyAdmin > database kuekumarinda_db > tab SQL > tempel isi database/qris_simulasi.sql > Go.
3. Tambahkan di file .env (ganti IP dengan IP laptop kamu, lihat bagian IP di bawah):
      QRIS_BASE_URL=http://192.168.1.10:8000
4. php artisan optimize:clear
5. Jalankan server agar bisa diakses HP:
      php artisan serve --host=0.0.0.0 --port=8000
   (XAMPP/Apache: cukup start Apache, lalu QRIS_BASE_URL=http://IP-LAPTOP/nama-folder-public)

MENCARI IP LAPTOP
   Windows: buka CMD > ipconfig > "IPv4 Address" pada adaptor WiFi (mis. 192.168.1.10)
   HP dan laptop harus tersambung ke WiFi yang SAMA.
   Bila HP tidak bisa membuka: izinkan php/Apache di Windows Firewall (Private network).
